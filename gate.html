우성고 카드 시스템

환경을 확인하고 있습니다.

확인 중...
  1. Safari 공유 버튼을 누릅니다.
  2. 더보기를 누른 뒤 홈 화면에 추가를 선택합니다.
  3. 추가를 누르면 홈 화면에 앱 아이콘이 생성됩니다.
  1. 아래 주소 복사하기 버튼을 누릅니다.
  2. Safari 브라우저를 실행합니다.
  3. 주소창에 붙여넣기 후 접속합니다.
  4. Safari에서 홈 화면에 추가를 진행합니다.
Chrome에서 설치하기 앱 바로가기
설치가 안 되면 Chrome 메뉴(⋮) → 홈 화면에 추가
이미 설치했다면 홈 화면의 우성고카드 아이콘으로 실행하세요.
